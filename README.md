# Рома ест 🍲

Сайт с любимыми блюдами, чтобы мама знала, что приготовить.

## Файлы
- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика (вкладки, случайное блюдо, открытие рецепта)
- `recipes.js` — **все рецепты и категории. Новые блюда добавляются только сюда.**
- `img/` — фото блюд

## Как добавить блюдо
1. Открой `recipes.js`, скопируй любой блок `{ ... },` и вставь в список `RECIPES`.
2. Поменяй `id` (латиницей, без пробелов), название, категорию и остальное.
3. Залей изменения в GitHub, и сайт обновится.

## Как добавить фото
1. Положи фото в папку `img/`, например `borsch.jpg`.
2. В рецепте укажи `photo: 'borsch.jpg'`.

## Публикация на GitHub Pages
1. Создай репозиторий и загрузи туда содержимое папки.
2. Открой Settings → Pages → Branch: `main`, папка `/root` → Save.
3. Через минуту сайт будет доступен по адресу `https://<ник>.github.io/<репозиторий>/`.

Ссылка на конкретное блюдо: `.../#borsch`
